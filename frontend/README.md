# Frontend CléService

Application React 18 construite avec Vite.

- `src/SiteWeb/` : site public, pages, composants et contextes.
- `src/AppAdmin/` : interface d'administration.
- `src/assets/` : ressources locales (images, icônes, polices).
- `src/main.jsx` : point d'entrée de l'application.

Commandes depuis la racine du dépôt : `npm run dev:frontend` et `npm run build:frontend`.
